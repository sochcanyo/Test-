# Mitt Fritsla

Testversion av webbappen Mitt Fritsla med kalender, evenemangsformulär och karta.

## Publicera via GitHub Pages

1. Skapa ett offentligt repository, exempelvis `mitt-fritsla`.
2. Ladda upp filen `index.html` i repositoryts rot.
3. Gå till Settings → Pages → Build and deployment → Deploy from a branch.
4. Välj `main` och `/(root)` och spara.
5. När publiceringen är klar öppnar du adressen som visas under Pages i Safari.

**Obs:** Inlägg sparas bara lokalt i varje webbläsare. Ingen gemensam databas, moderering eller riktig anmälningshantering finns ännu. Lägg inte upp privata uppgifter i testversionen. Kartan behöver internet.
